## 2026-06-03 — Verification checked SHAPE not SUBSTANCE; flagship FIRE number was absurd-but-green (#22)
**Mistake:** Shipped a FIRE headline showing a 30-yr-old dual-income couple retiring at **age 81** — and accepted it because type-check passed, the component rendered, console was clean, and unit tests were green. All my gates verify "does it render/persist/match the current computation" (SHAPE); none asked "is this number SANE for this person?" (SUBSTANCE). A human owner would have flinched at age 81 instantly; I didn't. Worse: my FIRST fix patched 1 of ~20 FIRE consumers (skipped the sibling sweep — fixed the symptom on one screen while committing the message about it).
**What it missed:** `derive()`'s member lens scoped savings/corpus to one earner but left expenses/fireNumber/familyLayer/bridge at household level → household FIRE target ÷ one earner = incoherent age 81 (true household 62). It hid because the seed test exercised `isFamilyView:true` (coherent path) while the product DEFAULT is `isFamilyView:false` — test and product DIVERGED, green on a path no user sees.
**Root cause:** (1) code — no invariant that the FIRE ratio's numerator + denominator use the same member set; the lens default fell back to `earners[0]`. (2) process — verification is mechanical-green, not semantic-plausibility; tests lock the current (possibly wrong) output instead of asserting domain-sane bounds; tests run a convenient lens not the default product lens.
**Fix/Pattern:** ROOT-fixed: the member lens applies ONLY on explicit member selection — default = whole household (one line in `derive.ts`), fixing all ~20 consumers at the source; deleted the leaky `forceHousehold` flag. FOOLPROOF system: (a) `src/lib/headline-plausibility.spec.ts` — every persona on the DEFAULT product lens, domain-sane bounds (FIRE age ≤ 70, savings 15-70%, all earners pooled) → "age 81" is now a CI failure; (b) new rule 31 + `.claude/rules/output-plausibility-verification.md` — verify SUBSTANCE not just shape, on the default product path, FinTech validates end-to-end headline (not just engine internals), shape-locks must be paired with a substance assertion. Standing heuristic: if a number looks absurd, STOP and root-cause — never accept green.
